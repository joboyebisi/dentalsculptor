## Project name

DentalSculptor

## One-line pitch

An agent-native 3D studio where AI coordinates dental teaching-case authoring while educators
retain control of anatomy, approval, privacy, and release.

## Short description

DentalSculptor uses WebMCP to turn image-to-3D dental case authoring into a reliable collaboration
between an educator and an agent. The agent can inspect live state, generate a model, configure a
clinical workflow, coordinate reversible edits, and prepare export or sharing in the same visible
workspace. The educator makes the spatial and clinical decisions.

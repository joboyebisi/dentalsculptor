# DentalSculptor Information Architecture & User Journey

## Site Map
1. **Public**
   - Landing Page (Marketing, Features, Community Showcase)
   - Login / Sign Up
2. **Onboarding**
   - Role Selection
   - Institution Details
   - Welcome/Quick Actions
3. **Internal App (Educator/Researcher focus)**
   - Dashboard (Overview, Recent Projects)
   - Projects (List, New Project Flow)
   - Authoring Workspace (3D Editor, AI Assistant)
   - Community Hub (Discovery, Cloning)
   - Students (Management, Assignments)
   - Research Dashboard (Metrics, Data Export)
   - Settings

## User Journey: "Image to XR Simulation"
1. **Landing**: User arrives, sees "AI-Powered Dental Learning" value prop.
2. **Auth**: Quick Google/Microsoft sign-in.
3. **Onboarding**: Identifies as "Educator", connects to University.
4. **Dashboard**: Clicks "+ New Project".
5. **Upload**: Drops a 2D clinical dental photo.
6. **Generation**: AI processes (Extraction -> Reconstruction -> Model).
7. **Authoring**: Opens in 3D Viewer. User annotates a lesion and accepts an AI suggestion to deepen a groove for a simulation.
8. **Educational Design**: Adds learning objectives and an assessment prompt.
9. **Deployment**: Previews in browser, then clicks "Launch in Meta Quest".
10. **Sharing**: Publishes to Community Hub.
11. **Research**: Researcher logs in later to see "Pedagogical Ownership" score for this project.
